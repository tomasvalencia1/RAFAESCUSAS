Dirección de arte para RafaConecta derivada del escudo real de la IE Rafael Uribe Uribe. Todo lo que ves aquí son los tokens y componentes que después se aplican a la app completa.

01 · Identidad

Del escudo al sistema

Muestreé los píxeles del logo.png real. El escudo tiene tres colores dominantes: rojo hsl(0 88% 38%), amarillo hsl(54 98% 52%) y azul hsl(195 89% 42%). Ninguno es usable tal cual en una interfaz, así que cada uno recibe un papel distinto y la corrección de luminosidad necesaria para cumplir AA.

La regla que evita el desastre

  • El granate nunca es interactivo. Vive en la marca, los avisos del profesorado y los kickers de sección. Si fuera también el color de los botones, cada error del sistema se confundiría con la identidad del colegio.
  • El azul es el único color de acción. Enlaces, botones primarios, pestaña activa. Si algo es azul, se puede pulsar.
  • El amarillo jamás es texto. Solo superficie de realce con texto oscuro encima (insignias «nuevo», subrayados, el guion del kicker). Sobre blanco no llega ni a 2:1.
  • El rojo de error es otro rojo. hsl(8 76% 42%), más claro y desplazado hacia el naranja, y siempre acompañado de icono y texto — nunca color a solas (WCAG 1.4.1).

02 · Color

Roles semánticos

Los componentes nunca nombran un color: piden un rol. Cambiar el tema es re-mapear estos roles, no reescribir componentes. Las variantes suaves se calculan con color-mix(), así que son un token, no quince.

Los ratios están calculados, no estimados. Los dos que fallaron en la primera pasada (texto atenuado 4.29:1 y warning 3.98:1) ya están corregidos a 4.93:1 y 5.04:1.

03 · Tipografía

Dos familias, escala 1.25, fluida

Fraunces (serif) solo para momentos de marca: el nombre de la app, los títulos de sección y los estados vacíos. Le da el peso institucional que pide un colegio sin volver la interfaz solemne. Inter para absolutamente todo lo demás — es la que ya carga la app hoy, así que no hay regresión de rendimiento.

05 · Moldeable

Añadir o quitar opciones sin tocar el HTML

Pediste que la interfaz sea moldeable. Esa es una decisión de arquitectura, no de estilo: hoy, cambiar el menú exige editar index.html, styles.css y varios puntos de app.js. En el rediseño, la navegación y las acciones se declaran en un único array de configuración y la interfaz se genera a partir de él.

// js/config/navegacion.js ← el único archivo que se toca export const SECCIONES = [ { id: 'feed', etiqueta: 'Inicio', icono: 'bx-home', roles: ['*'] }, { id: 'noticias', etiqueta: 'Noticias', icono: 'bx-news', roles: ['*'] }, { id: 'excusas', etiqueta: 'Excusas', icono: 'bx-file', roles: ['estudiante','profesor','admin'] }, { id: 'eventos', etiqueta: 'Eventos', icono: 'bx-calendar', roles: ['*'] }, { id: 'chat', etiqueta: 'Chat', icono: 'bx-chat', roles: ['profesor','admin'] }, { id: 'moderar', etiqueta: 'Moderar', icono: 'bx-shield', roles: ['admin'] }, ]; // Quitar «Juegos» = borrar su línea. // Añadir «Biblioteca» = añadir una línea. // Restringirla a profesores = cambiar roles: ['profesor'].

El mismo patrón se aplica a los elementos del menú de perfil, a las acciones de cada publicación y a los campos del formulario de excusas. La visibilidad por rol deja de estar repartida en clases CSS como .admin-only o .student-hidden y pasa a estar en un sitio único y legible.

07 · Notas de dirección de arte

Las decisiones, y por qué

  • Composición. Rejilla de 12 columnas con contenedor de 72 rem y canalón fluido clamp(1rem, 0.6rem + 2vw, 2.5rem). El feed se limita a ~68 ch de ancho de lectura: por encima de eso el ojo pierde el renglón. Punto focal único por pantalla — en el feed es la publicación más reciente, no el menú.
  • Contraste. Texto principal a 16.5:1 y secundario a 6.0:1, muy por encima del mínimo. El contraste cromático separa las secciones: fondo hundido para la zona de scroll, superficie blanca para las tarjetas. Nada de grises claros sobre blanco.
  • Whitespace. El espacio hace el trabajo que antes hacían los bordes y las sombras. Secciones a --space-12, tarjetas con --space-5 interno, y aire entre el avatar y el nombre para que el bloque respire. Donde dudé, puse más aire.
  • Movimiento. Solo tres transiciones en todo el sistema: color de fondo, color de borde y un translateY(-1px) en los botones. 150–220 ms con cubic-bezier(.22,.61,.36,1). Todo se desactiva con prefers-reduced-motion.
  • Lo que se elimina. Los degradados decorativos, los glows de color, el backdrop-filter generalizado y el design system de terceros servido desde rawcdn.githack.com — un CDN de desarrollo que hoy es una dependencia de producción y además pelea con styles.css.
